# Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar e aprofundar os conhecimentos em **JavaScript**, aplicando conceitos fundamentais da linguagem em um projeto prático.

Durante o desenvolvimento, foram explorados recursos como manipulação do DOM, eventos, lógica de programação, funções, estruturas de repetição, condicionais e organização do código, sempre buscando escrever um código limpo e de fácil manutenção.

Mais do que um projeto concluído, este repositório representa uma etapa do meu aprendizado, servindo como um ambiente para experimentar novas abordagens, fortalecer a lógica de programação e evoluir como desenvolvedor.

## Objetivos

- Praticar JavaScript na criação de aplicações reais.
- Aprimorar a lógica de programação.
- Explorar manipulação do DOM e eventos.
- Aplicar boas práticas de organização e legibilidade do código.
- Consolidar os fundamentos da linguagem por meio da prática.

> **Observação:** Este projeto foi desenvolvido exclusivamente para fins de estudo e aperfeiçoamento técnico.
